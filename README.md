# Epic 免費遊戲自動領取

每週自動打開 **Epic Games 啟動器**，像人一樣用滑鼠點選，把商店裡所有「現在免費」的遊戲加進收藏庫。

- 不需要輸入帳號密碼，直接使用啟動器裡已登入的帳號
- 用 Windows 內建的文字辨識（OCR）讀畫面，找到按鈕再點
- 一次領完所有免費遊戲，已擁有的會自動跳過
- 遇到人機驗證或其他意外就停下來，跳出視窗請你手動處理（不會嘗試破解驗證）

## 運作流程

```
Windows 工作排程器（每週五 12:00）
        ↓
run.bat → claim_epic.py
        ↓
1. 開啟 Epic 啟動器並最大化，暫時縮小擋在前面的「最上層」視窗
2. 回到商店首頁，找出所有標示「現在免費」的遊戲
3. 逐一點進去 →「獲取」→「新增至收藏庫」→ 確認出現「感謝訂購」
4. 寫入 claim_log.txt，還原剛才縮小的視窗
```

## 需求

- Windows 10 / 11
- Python 3.10 以上
- 已安裝並登入 Epic Games 啟動器
- Windows 的**繁體中文 OCR 語言套件**（系統語言是繁體中文通常已內建）
- Epic 啟動器介面語言為**繁體中文**（程式是比對畫面上的中文按鈕文字）

## 安裝

1. 下載或 clone 這個專案
2. 在專案資料夾按右鍵 →「在終端機中開啟」，執行：

   ```powershell
   powershell -ExecutionPolicy Bypass -File .\setup_task.ps1
   ```

   這會把套件安裝到 `lib` 資料夾，並建立每週五 12:00 執行的排程「Epic 免費遊戲自動領取」。

想立刻試跑一次，直接雙擊 `run.bat`。

## 注意事項

- 執行時電腦必須開機並登入 Windows（程式需要看得到畫面）；週五中午沒開機的話，下次開機會自動補跑
- 執行約 1 分鐘，期間請不要操作滑鼠鍵盤
- Epic 每週四晚上 11 點（台灣時間）更換免費遊戲
- 記錄在 `claim_log.txt`；失敗時的截圖存在 `screenshots/`；程式無法啟動時的錯誤在 `run_output.txt`

## 移除排程

```powershell
schtasks /Delete /TN "Epic 免費遊戲自動領取" /F
```
